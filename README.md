# QuickTextPaste-Mac

Вставка готовых текстов по горячим клавишам для macOS. Работает как Windows-программа [QuickTextPaste](https://www.softwareok.com/?seite=Freeware/QuickTextPaste) от SoftwareOK.

> Неофициальный проект, написан с нуля на Swift. К SoftwareOK и автору оригинала отношения не имеет.

## Что умеет

- **Тексты на горячих клавишах.** Нажимаешь, например, ⌃⌥1, и текст вставляется туда, где стоит курсор, в любой программе.
- **Автотекст.** Набираешь сокращение, например `прив`, и оно заменяется текстом. Срабатывает после пробела или знака препинания либо сразу после последней буквы. Регистр не важен, внутри слова не срабатывает.
- **Ограничение по программам.** Клавиша может работать только в нужных программах (`Telegram, Safari`) или везде, кроме некоторых (`!Terminal`).
- **Всплывающие меню.** Одна клавиша открывает меню из нескольких текстов (`MenuName:` / `MenuBreak:`).
- **Значок в строке меню.** Оттуда можно выбрать любой текст, сгруппированный по папкам.
- **Меню всех текстов** по отдельной горячей клавише (по умолчанию ⌃⌥V).
- **Команды внутри текста:** дата и время, паузы, нажатия Tab и Enter, преобразования текста из буфера обмена, открытие сайтов и программ.
- **Буфер обмена.** После вставки возвращается то, что в нём было до неё. Менеджеры буфера эту вставку не запоминают.
- **Данные.** Резервная копия раз в день, импорт и экспорт в JSON, автозапуск при входе в систему, окна поверх остальных.

## Команды

| Команда | Что делает |
|---|---|
| `%DATE%`, `%TIME%`, `%DATETIME%` | дата и время (формат задаётся в настройках) |
| `%DATE:yyyy-MM-dd%` | дата в своём формате |
| `%sleep_200%` | пауза 200 мс |
| `%send_tab%`, `%send_enter%`, `%send_esc%` | нажать клавишу (также `up`, `down`, `left`, `right`, `space`, `backspace`, `delete`, `home`, `end`) |
| `%TAB%` | символ табуляции |
| `%copy_text%` | текст из буфера обмена |
| `%copy_text_uc%` / `%copy_text_lc%` | буфер ЗАГЛАВНЫМИ / строчными |
| `%copy_text_ucFirstWord%`, `%copy_text_lc_ucFirstWord%` | первая буква заглавная |
| `%copy_text_ucFirstAllWords%`, `%copy_text_lc_ucFirstAllWords%` | Каждое Слово С Заглавной |
| `%copy_text_mix_lc_uc%` | вПеРеМеШкУ |
| `%copy_text_escape%` | экранировать `\ " '` и переносы строк |
| `%cpy_txt_urlencode%` | закодировать буфер для ссылки |
| `%USERNAME%`, `%UserProfile%` | имя пользователя и домашняя папка |
| `%pastehtml%` | в начале текста: вставить как HTML |
| `run:адрес` | с новой строки: открыть сайт, файл или программу |
| `MenuName:Название` | с новой строки: пункт всплывающего меню |
| `MenuBreak:` | с новой строки: разделитель в меню |

Пример меню:

```
MenuName:Привет
Привет! Чем могу помочь?
MenuName:Спасибо
Спасибо, жду ответа!
MenuBreak:
MenuName:Поиск по буферу
run:https://www.google.com/search?q=%cpy_txt_urlencode%
```

## Сборка

Нужны macOS 14 или новее и Xcode Command Line Tools (`xcode-select --install`).

```bash
./build.sh
```

Готовое приложение появится в `build/QuickTextPaste.app`. Его можно перетащить в «Программы».

Тесты (работают с копией `texts.json`, сам файл не меняют):

```bash
./tests.sh
```

## Разрешение «Универсальный доступ»

Без этого разрешения macOS не даёт программам вставлять текст в другие окна. При первом запуске появится запрос. Если запроса нет, открой: Системные настройки → Конфиденциальность и безопасность → Универсальный доступ → включи QuickTextPaste.

Сборка подписывается без сертификата разработчика, поэтому после каждой пересборки macOS может сбросить разрешение. Тогда выключи и снова включи программу в этом списке.

## Где хранятся тексты

`~/Library/Application Support/QuickTextPasteMac/texts.json`, резервные копии лежат в `Backups/` рядом с ним.
